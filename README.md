# Shortest Path Simulator

# About the Project
The Shortest Path Simulator is a web-based application that helps users visualize how pathfinding algorithms find the shortest path between two points on a grid.

It is built using HTML, CSS, and JavaScript.

# Features
- Interactive grid for pathfinding.
- Set a starting point and destination.
- Add obstacles to the grid.
- Visualize the pathfinding process.
- Compare Dijkstra's algorithm and the A* algorithm.
- Display the path found by the selected algorithm.

# Algorithms Used

# 1. Dijkstra's Algorithm
Dijkstra's algorithm finds the shortest path by exploring nodes based on their current distance from the starting point.

# 2. A* Algorithm
A* uses the distance already travelled and a heuristic estimate of the distance remaining to the destination to guide its search.

# Technologies Used
- HTML
- CSS
- JavaScript
